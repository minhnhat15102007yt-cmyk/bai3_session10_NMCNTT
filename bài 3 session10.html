Phần 1. Phân tích bài toán

Giải thích tại sao Markdown lại giúp AI xử lý nhanh hơn dựa trên cơ chế chia nhỏ Token

  • 1.token là gì : Là đơn vị văn bản AI dùng để xử lý. Càng nhiều ký tự cú pháp, càng tốn nhiều token và chậm tốc độ phản hồi.

  • 2.tại sao Markdown tối ưu hơn HTML :

  • Ít rác cú pháp: Markdown dùng ký hiệu ngắn gọn (**, #, -) thay vì các cặp thẻ dài dòng của HTML.

  • Tiết kiệm chi phí & tăng tốc: Giảm số lượng token giúp hệ thống AI phản hồi nhanh hơn và tiết kiệm chi phí gọi API đáng kể.
